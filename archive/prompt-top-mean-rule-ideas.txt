SELECTION-INVARIANCE LAW
A ranking changes an event only if another candidate beats the frozen winner under
(rule value, FNV digest). Any rule of the form g_event(cand.score) with g_event
strictly increasing is banned because it preserves ordering and ties. Event-only
terms, positive event-only multipliers, and event-only offsets cannot change
within-event ordering. A filter changes the pick only if it rejects the winner and

events and are banned. cand.longEligible is always true and cand.score is always
positive in the base pool. Monotone-in-signedVotes is not banned by itself (there is
no quota).
