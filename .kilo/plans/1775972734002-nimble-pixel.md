on crypto (BTC/ETH/SOL). All use very short lookbacks (5–15 bars), session-aware context via
`calculateSessionVWAP`, and microstructure-heavy helpers. Default secondary symbols match the
crypto options universe (BTCUSDT as benchmark, ETHUSDT as peer, SOLUSDT as high-beta sector).

## 1-Min Gamma/Scalp Design Principles
- **Very short lookbacks** (5–15 bars = 5–15 minutes) for fast triggering
- **Session VWAP** as intraday value anchor for mean-reversion and compression detection
- **Microstructure signals** (initiative pressure, sweep-reclaim, close acceptance, body pct)
  are more informative on 1-min than longer timeframes
- **Directional conviction** is critical — gamma scalps need to know which way to hedge
- **Volume participation** on 1-min captures rapid capital rotation between crypto assets
- Mix of: momentum (for buying calls/puts), vol-expansion (for buying straddles),
  and reversion (for gamma scalping around session value)
